Architecture

The generator is a three-branch local SE(3)-equivariant EquiformerV3 that maps a bank of random initial structures to generated structures in a single forward pass. Each layer applies, in sequence:

  1. Slab self-attention — full slab → full slab
  2. Adsorbate self-attention — adsorbate → adsorbate
  3. Cross-attention — bidirectional slab ↔ adsorbate (reads features already updated by self-attention)
  4. FFN residual

All valid nodes (including fixed slab atoms) update their hidden features in attention and FFN residuals, but only movable surface and adsorbate atoms receive coordinate residuals. Coordinate residuals are read from l=1 features, so the displacement field is SE(3)-equivariant by construction.

Condition information is injected via FiLM modulation from the factorized condition encoder, which encodes primitive cell, Miller index, termination, supercell matrix, layer count, vacuum, strain, and adsorbate identity as independent construction factors.
