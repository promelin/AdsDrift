What is AdsDrift?

AdsDrift maps randomly initialized structures distributed across a surface to a set of candidate structures near low-energy endpoints in a single generator forward pass. Given a fixed surface-adsorbate system, it learns the distribution of low-energy configurations and generates structures that can be deduplicated, ranked by energy, and subjected to short relaxations.

The generator is a three-branch local SE(3)-equivariant EquiformerV3 that updates slab self-attention, adsorbate self-attention, and bidirectional slab↔adsorbate cross-attention in sequence. Coordinate residuals are read from l=1 features, making the learned displacement field equivariant by construction.

Not included in this repository

Training data, trained checkpoints, and MACE-MH-1 weights are not distributed. MACE-MH-1 must be obtained separately from its official model page and used per the upstream ASL license. Set ADSDRIFT_MACE_CHECKPOINT to the local checkpoint path for training. The R0 sampling and architecture demos on this dashboard run entirely without these external dependencies.
